# Mode lifecycle and extension map

## Runtime sequence

```text
CLI args
  -> src/cli.rs allocates Grid, seeds StdRng, resolves palette, reads ASCII_T
  -> src/registry.rs resolves &'static dyn Mode
  -> Mode::render receives one borrowed ModeFrame
  -> the file-owned renderer or compositor
  -> src/gridio.rs emits serialized or ANSI output
```

Interactive animation uses the same inputs:

```text
src/opts.rs persisted knob values and names from registered_modes()
  -> dyn Mode declarations for params and AnimKind
  -> src/morph.rs calls Mode::render for in-process frames
  -> subprocess render_frame_t fallback with ASCII_T
```

`iterate_grid` is the low-latency native path. The subprocess fallback also forwards `ASCII_T`, so a time-aware CLI handler can animate before an in-process arm is added.

## Registry surface

Every generated-registry mode implements:

```rust
struct NameMode;

pub(super) static MODE: NameMode = NameMode;

impl Mode for NameMode {
    fn name(&self) -> &'static str;
    fn help(&self) -> &'static str;
    fn animation(&self) -> AnimKind;
    fn params(&self) -> &'static [Param];
    fn render(&self, frame: &mut ModeFrame<'_>) {
        // Parse frame.args and parameter values.
        // Render from frame dimensions, seed, palette, RNG, and time.
    }
}
```

`ModeFrame` borrows the grid, palette, RNG, and argument slice for one call. `registered_modes()` owns a process-global `OnceLock<ModeRegistry>`. Each registry value is a reference to a file-owned zero-sized static implementation. Names are unique because `ModeRegistry::add` rejects replacement.

`scripts/0_generate_modes.sh` scans `src/modes/_[0-9]*_*.rs` and writes ordinary Rust `mod` declarations plus `register_all`. `scripts/1_dev.sh` runs that generator every 0.5 seconds while the development process is alive.

## Registration checklist

| Registration | Required condition |
|---|---|
| `src/modes/_N_name.rs` | One file-owned `Mode` implementation and `MODE` static |
| `src/modes/mod.rs` | Generated by `scripts/0_generate_modes.sh` |
| `src/modes/snapshots/` | Every canonical mode, fixed seed |
| `AGENTS.md` | Architecture or workflow changes; mode names are discovered from code |
