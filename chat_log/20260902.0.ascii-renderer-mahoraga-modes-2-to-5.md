## Solution/Approach
Everything is per-cell sampling, never glyph drawing:
cell -> figure uv (u right, v down, 1.0 = figure height, 2:1 cell aspect handled by 2*fig_h horizontal scale)
 -> displace across cut planes (shear slip, bright stroke inside blade band)
 -> Fuga beam (v5) -> Sukuna body -> Mahoraga body (min tapered-capsule SDF over bones) -> edge outline -> ghosts -> speed lines -> aura -> near blocks -> shrine -> far blocks -> ground (crater, rays, rubble) -> sky haze.
Shading: fake normal from SDF gradient, dot light, dither, ramp " .·:-=+*%@"; cloth ramp; wrap bands; wheel handles lit per adaptation.
Rig (v4/v5): BoneDef {parent, anchor, off, len, rest world angle (0 down, +pi/2 right), r0, r1, part, z}; solve() FK: ang = parent_ang + (rest - parent_rest) + delta. Poses = delta vectors; blend lerp; per-seed noise; t>0 sway + breath; 2-bone IK (law of cosines) aims the arm on the target's side at Sukuna's lead hand.
v5 Body::sample picks nearest-z bone among containing capsules, Part::Contour where a nearer bone's edge overlaps a farther one.
Animation clock: progress p = t*speed mod (fuga+3); adaptations = floor(p); wheel turn eased in first 30%; Fire Arrow reach = p - fuga + 1. Keyframe cycle (v5): stand, adapt, flinch, guard, point, lunge, swing with HOLD units each.

## Key Insights
- Python heredoc edits via `python3 - <<'EOF'` in this sandbox sometimes fail `str.index` on strings that grep finds; writing the script to the scratchpad file and running it works reliably.
- Registry splice once produced `},    ModeForm {` on one line and `},];` at the end; check with `grep -n '},    ModeForm\|},\];' src/registry.rs`.
- Snapshot accept: `mv *.snap.new *.snap` in src/snapshots and tests/snapshots (integration tests only run after bin tests pass, so accept in two rounds).
- Glyph width: '═' (U+2550) and box chars pass the display-width test; '◆' '◉' '·' already in repo pools.
- Arrow test signature: "=====" / "~--~--~--" runs; cloth ramp and crater can produce short '=' and '~-' runs, so use long patterns.
- Cut glyph: '─' only when |dx| > 5|dy| in screen space, else '/' '\\', or shallow cuts render as staircases of dashes.
- IK across the body hides the arm inside the torso SDF; choose the arm on the target's side (v4 fix) or use z-order (v5).
