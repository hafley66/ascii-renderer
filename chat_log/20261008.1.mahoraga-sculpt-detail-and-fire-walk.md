## Key Insights
- `viewer.html` bakes the walk from the Rust `KEYS`; `skin.html` poses procedurally from
  gait knobs + IK. The portable form for the mode is the Rust keys or a Rust gait module.
- An arm reads straight front-on when the only elbow motion is pitch (foreshortened); a
  sideways tuck (negative spread at the elbow) creates the visible hanging kink.
- `skin.html` ink = inverted hull (BackSide) only; `viewer.html` adds `owner` + `crease`
  seams with threshold `INK_CREASE`.
- Muscle borders ink only where the SDF has a valley AND the owner changes; `detail`
  shapes (hard union) create those valleys. Crease probe `e 0.16` reads them.
- Harness: same-path hash-only navigation does not reload -> use a `?v=N` cache buster;
  the skin viewer hash must start with `#?`. Browser tabs auto-freeze/close at turn
  settle; reopen with `browser.open({persist:true})`.
