## Problem/Context
Sandbox SIGTERMs the crate's custom linker (`-C linker=/Users/chrishafley/projects/instant/scripts/sign-link.sh`) at the final bin link step. `cargo check` passes in sandbox; `cargo build` / `cargo test` need the sandbox off (dangerouslyDisableSandbox) or the binary stays stale and renders the default SKILLS splash for the new mode name.

## Solution/Approach
Architecture (both files):
- thread_local `CACHE: RefCell<Option<Cached>>` keyed by (w, h, seed, geometry knobs). build() once: recursive `grow` (branch factor 2/3, prune at depth), `fit` scales origin-centred segs into the box, `raster` into a dense `Vec<Option<TreeCell>>` (last write wins, sub-cell segs skipped past lvl 2), leaf `blob`s only fill empty cells at 72%, edge detection marks LeafEdge, colors baked per cell (lifetree: one rgb by static side; lifetree2: eth + phys + phys_alt).
- frame(): bg row memcpy/fill, then one linear pass over cells; all motion is f(t) with per-item phases, zero rng, zero alloc. t == 0 is the canonical snapshot frame.
- lifetree2 side test is per-frame `is_eth(x,y) = x < veil[y]`, veil = seam + tide sweep + two travelling harmonics; `veil: [i32; 512]` on the stack.
- Wiring per add-mode skill: cli.rs import + help line + last dispatch arm, main.rs mod, opts.rs all_modes, registry.rs MODE_FORMS row (append at end of the static, not the file), morph.rs iterate arm, tests/snapshot_modes.rs, CLAUDE.md.

Knobs (env ASCII_P_*): shared DEPTH SPREAD SWAY SPEED MOTES GLOW SEAM ROOTS; lifetree2 adds VEIL SEASON RING TIDE GUST SURGE FLOCK DAY FLAIR. Positional args: tree-of-life [depth sway speed motes seam]; tree-of-life-2 [depth sway speed motes seam veil season tide gust flair].

lifetree2 clocks: tide ~57 s sweep, gust envelope smooth(sin mix), surge su=(ts*0.16).fract() root front then canopy front then burst (sparks from cached tips, negative flash for su in 0.74..0.79), heartbeat 3 s double beat with bg flash and hashed row shear, day sun_a=ts*0.07*DAY with sun ◉ moon ○ and per-row sky lerp, seasons tent weights over a 0..4 phase. Flair: seam scrolls `ARBOR·VITAE·MEMENTO·MORI·ANIMA·MUNDI`, canopy reflection `˙ ·` below the ethereal horizon.
