## Scope this pass

- Sculpt detail: muscle masses, insertion sites, separation creases, fiber texture.
- Not scope: rig joint positions, walk timing, the ASCII mode itself.
- Iteration loop is code change then read the rendered contour image, via the
  `browser` tool (Playwright) element-screenshotting the `#cont` canvas, NOT the
  slow `--headless=new --use-angle=swiftshader` CLI path.

## What I judged achievable before editing

- Muscle separation reads in the contour viewer only where the distance field has a
  valley at the muscle border (the viewer inks `owner` changes whose crease exceeds
  1.2). Muscles currently authored as `core` melt at blend 0.4 and produce no border.
  Moving superficial muscles to `detail` (blend 0.08) turns their borders into ink.
- Highest front-view payoff: pecs (two heads, sternum groove, arcing lower border),
  rectus block (linea alba plus tendinous rows), obliques/serratus flank, and a
  visible neck under the skull.
- Head: rebuild as a tall narrow wedge (brow V, cheek flare, square tooth grille,
  blocky chin) instead of the round cone blob.
- True high-frequency fiber striations are not resolvable at the current voxel size;
  fiber reads must come through crease seams and the wireframe, not fine geometry.
