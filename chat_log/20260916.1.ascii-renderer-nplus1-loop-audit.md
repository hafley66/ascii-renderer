## Key Insights
- The `convert` phase is a flat 19.6 ns/cell (1430 us at 366x199) whether 72,834 or 39,944 cells changed; `emit` is what responds to churn. So plan step 2 is worth ~1.4 ms/frame, not 3.4 ms.
- The repo's logger is `hafley_observe` (Cargo.toml:28) + `tracing`/`tracing-subscriber`, initialised in `_0_profile::init()` from `src/main.rs:143`. Unit tests have NO subscriber, so `tracing!` in a test is a silent no-op; the repo's own tests use `eprintln!` (`_1_playback.rs:611,620`, `arboretum.rs:1122`). A gate's channel is its assertion — the coverage print was removed.
- Roster gap: `NATIVE_MODES` (65 names, the sweep's subset) omits 13 registered modes (tideglass, chimera-shadow-garden, volute, astra-opus-1-chronofold, astra-jurassic-park, astra-chaos-theory, terminal-stress, gem-aetherium-3, azulejo, bower, gem-aetherium-2, moonwake, vesper) and the old gate could not see them; 8 of those had no timers at all. The new gate covers the registry instead.
- `extract`'s df family is the loop/N+1 instrument: `df_nest.depth ≥ 2` IS the per-cell set; `df_loop.collection` names what a loop walks. `extract fast` is parser-authoritative for syntax facts and self-labels its resolution guesses, so only its syntax facts are trustworthy today.
- `extract` supports Rust (`--indexer rust` is in the roster; CST parses; `extract rename` / `extract move` both exist as AGENTS.md claims). `fast` mode leaves `function_item.name` null, so function names had to be recovered from spans + source bytes.
- Measurement discipline that paid: interleaved same-build A/B (two encoders, alternating per rep, byte-equality asserted) for equal-load comparisons; forced-gate builds for the parallelism crossover; FNV grid hashes for bit-identity. Naive before/after across a load change produced a false 6-13% regression signal.
- Pre-existing failures to never re-debug: gridio ansi RGB-level test and morph `gem_bad_roll6_ansi_regression` (both reproduce on pristine), and `polytope::snapshot_polytope_small` which PASSES in debug and FAILS in release on untouched HEAD code (one glyph `:` vs `.` across a float threshold).
- insta needs `env -u CI` in this environment (CI=true blocks writes) and `CARGO_MANIFEST_DIR` must be unset; `.snap.new` files must never be left behind.
- `AnsiFrameEncoder::encode(grid, force_full, out)` — the bool is force_full, not "animated"; passing true makes delta measurement meaningless. `runs` counts row-runs, not attribute spans.
- The iTerm2 wall is iTerm2's own attributed-string drawing; tmux adds a second parser and costs DEC 2026 sync output (our `synchronized_output_for` requires TERM_PROGRAM=iTerm.app AND !in_tmux). xterm is not in the stack (`TERM=xterm-256color` is just tmux's capability string).
