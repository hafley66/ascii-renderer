## Problem/Context
Interactive Illuminarium performance appeared poor despite the fixed-grid renderer. Headless results show render and encoding CPU remain below the 60 FPS budget at large grids. The terminal path is excluded from the headless measurement and remains the largest unmeasured boundary.

At 480x135, the diff encoder handles an average of 7,963 changed cells through 2,767 dirty runs per frame, around 2.9 changed cells per run. It produces 145,448 bytes per frame versus 305,445 bytes for full encoding. Diff encoding costs 1.337 ms versus 0.920 ms for full encoding. At 60 FPS the diff stream projects to about 8.73 MB/s and 166,000 cursor runs per second.

## Solution/Approach
- Keep mode animation parametric and deterministic from seed, dimensions, time, palette, and knob values.
- Retain the frame grid, RNG allocation, previous terminal frame, dirty flags, runs, and ANSI output buffer across animation frames.
- Use `hafley-observe` for opt-in human or JSON tracing controlled by `ASCII_PROFILE`, `ASCII_PROFILE_EVERY`, `ASCII_PROFILE_LAYERS`, `RUST_LOG`, and `HAFLEY_LOG_FORMAT`.
- Separate headless compute measurements from terminal presentation measurements.
- Use release-only fixed-input probes for averages and p50/p95/p99/max rather than development builds.
- Preserve painter order and snapshot identity while instrumenting.

## Key Insights
- ANSI diff encoding is 68.1 percent of headless compute at 480x135.
- Rose lattice is 60.8 percent of Illuminarium generation time.
- Guilloche is 17.9 percent of generation time.
- CPU generation plus encoding has substantial 60 FPS budget headroom at 480x135.
- The projected terminal stream and cursor-run count are large enough that terminal parsing/display must be measured separately before attributing interactive latency to render computation.
- Layer tracing adds some overhead. Generation averaged 0.591 ms without layer events and 0.626 ms with them.
- Static cache invalidation is keyed by seed, dimensions, palette, and effective knobs. Animation time only enters the dynamic pass.

- Does the filigree spike repeat at specific frame times or only under scheduler interruption?
