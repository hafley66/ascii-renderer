## Key Insights
- Every measured "terminal is slow" number before today was the relay's own poll/EAGAIN/sleep cycle at 1 KB per ms; `cat` into the same pane did 10x more.
- Delta encoding cannot drop frames at the relay (diff chain); flow control must be worker-side acks.
- tmux coalesces redraws, so `cat` throughput overstates per-frame paint capability of the emulator behind it.
- xterm.js DOM renderer is the current wall in instant (12 paints/s vs 56 frames/s); WebGL addon needs xterm >= 6.1.0-beta.304.
