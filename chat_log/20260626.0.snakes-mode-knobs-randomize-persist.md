## Problem/Context
Single-binary ASCII renderer (`src/main.rs` is ~15k lines). Animation flows through a declarative `ModeSpec`/`AnimKind` system: modes animate via the morph player (`morph_session`) or native time `T` (`iterate_grid` in-process, or subprocess via `ASCII_T`). Demo browser is `run_demo`. Knob values flow demo -> env `ASCII_P_<KEY>` -> renderer via `param_f32(key, default)`.

## Solution/Approach
- circuit: refactored body into `draw_circuit(... t ...)`; topology stays seed-fixed, a bright "current" pulse flows along each trace by `t`. Wired into `iterate_grid`.
- snakes (new mode): each snake rides a hidden, seamless toroidal closed loop; only a sliding body-window of length L is drawn, so it crawls forever with no teleport. Built by `snake_walk` (random walk: 65% straight, else 90% turn, never reverse; closes with a short straight return leg so net displacement is 0). Box-drawing bodies (`snake_seg`), `◉` heads, fading tails, `╬` crossover knots where two snakes meet perpendicular. Wraps at canvas edges (cells `rem_euclid` w/h).
- Form registry: `param!` macro + `MODE_FORMS` table + `mode_spec` scan. Adding a mode's config form is now one inline row.
- snakes knobs: COUNT, TURN, SPEED, LEN, HOP, HOPC, RBOW. Read in `draw_snakes` via `param_f32` (CLI arg is fallback for COUNT).
- rainbow (RBOW): per-snake hue spread blended over palette via `lerp_color`/`hsl_to_rgb`.
- hops (HOP chance + HOPC coef): occasional fast block-dash (`█`). Tuned down per feedback ("too strong, too linear"): default coef 0.4, range 0.2..1.5; cooldown `hop_len+3..8` prevents chaining; the hop wanders (30%/cell kink) so it's a short curvy block-cluster not a ruler. `snake_walk` returns a parallel `block: Vec<bool>`.
- randomize toggle (`g`): global deterministic<->random for all knobs. `effective_pvals(spec, pvals, seed, randomize, roll)` returns tuned pvals or per-seed random samples (`rand_knob` = hash of seed+key snapped to step). Left/Right (and +/- in animator) bump a `roll` nonce to re-roll a fresh set without changing seed (this was the last fix -- editing was hitting hidden pvals).
- persistence: `~/.config/ascii-renderer/options.tsv` (`mode<TAB>KEY<TAB>value`). `load_options`/`save_options`/`load_options_from`/`save_options_to`, `pvals_for` (clamps), `store_pvals`, `store_randomize`/`load_randomize` (reserved `__global/RAND` row). Both run_demo and morph_session load on entry + save on change -- unifies them so tuning carries browse->animate->next session.
- picker (`/`): Up/Down wrap around (cancel_idx is bottom). Cursor already init'd to current mode.

## Key Insights
- SANDBOX GOTCHA: the test binary went stale/corrupt and hung at startup with zero output for ALL tests (even untouched ones). Fix: `touch src/main.rs` + force recompile. Not a code bug. Burned a lot of time chasing a phantom infinite loop.
- Backgrounding the renderer with `&` causes SIGTTIN stop (false "hang"); run foreground. No `timeout` binary on this macOS -- use `perl -e 'alarm N; exec @ARGV' ...` (alarm survives exec).
- Grid dump format is `codepoint r,g,b` per cell; diffing needs awareness that same codepoint + different rgb = topology stable, color moved.
- Toroidal seamless loop = sequence of unit moves whose net displacement is 0; store per-cell step dir (not coord delta) so the wrap seam renders as a continuous line.
- Defaults chosen so HOP=0/RBOW=0 preserve prior output => snapshots never churn from added knobs. Per-snake speed rng draw change DID move the snapshot once (regenerated + reviewed).
- clock advances ~0.06/frame; pulse/snake speed ~3-5 cells/t-unit reads smooth.
